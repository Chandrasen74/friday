# Contributing

Thanks for your interest in FRIDAY.

## Getting started

1. Clone the repository and create a branch for your change.
2. Make focused, well-described commits.
3. If your change affects behavior or setup, update the README or relevant docs.
4. Open a pull request describing the change, motivation, and how it was tested.

## Development notes

- FRIDAY is an Android project (Kotlin, Jetpack Compose). Use JDK 17 and a compatible Android SDK/Gradle setup as documented in the README.
- Do not commit secrets, API keys, keystores, or personal data.
- Keep changes scoped; prefer separate PRs for unrelated fixes.

## Reporting issues

Please use the issue templates and include reproduction steps, device/Android version, and relevant logs (with sensitive data removed).
